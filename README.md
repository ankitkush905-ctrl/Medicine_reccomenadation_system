# Medicine_reccomenadation_system
🩺 AI Healthcare Assistant

About

An ML-based web application that predicts a possible disease based on user-selected symptoms using a Support Vector Machine (SVM) model.

Features

- Symptom-based disease prediction
- Disease descriptions and precautions
- Medication, diet, and workout information
- Interactive Streamlit dashboard

Technologies

Python, Pandas, Scikit-learn, SVM, Streamlit, HTML, CSS.

Dataset

- 4,920 records
- 132 symptom features
- 41 disease classes

Run Locally

pip install streamlit pandas scikit-learn
python -m streamlit run app.py
